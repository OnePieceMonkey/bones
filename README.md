# Bones

**The skeleton under every AI decision.**

The AI reads and proposes. Versioned rules decide. Every decision becomes an X-ray you can replay.

Built with [Kiro](https://kiro.dev) for Kiroween 2026 (category: Skeleton Crew).

## Apps
**Case Files** (`apps/case-files`) is a ghost detective game on the Bones skeleton. A solver proves that exactly one suspect can be convicted, and unfair cases are rejected. It runs offline on three hand-written recorded cases. Live mode is not built. Run it with `pnpm dev:case-files`. Details are in [apps/case-files/README.md](apps/case-files/README.md).
